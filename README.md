# AWS IAM Static Policy Auditor

A lightweight security utility designed to analyze AWS IAM policies for security risks, over-privileged permissions, and common misconfigurations.

## Features
- Scans static AWS IAM JSON policies for wildcard permissions (`*`).
- Detects privilege escalation vectors and overly permissive actions.
- Easy-to-use command-line interface (CLI) built with Python.
